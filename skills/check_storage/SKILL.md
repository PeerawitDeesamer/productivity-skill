# check_storage

รันสคริปต์นี้ แล้วรายงานผลเป็นภาษาไทย:

```bash
python3 ~/.claude/skills/check_storage/scripts/check_storage.py
```

สคริปต์ใช้เวลาหลายวินาทีถึงไม่กี่นาที ตั้ง timeout ให้ 600000 ms

## วิธีรายงาน

1. เปิดด้วยคำตอบ: แอปที่กินพื้นที่มากที่สุด และโฟลเดอร์ที่ใหญ่ที่สุดใน Documents
2. แสดงตาราง Application และตาราง Documents จากผลของสคริปต์
3. ถ้าตัวอันดับ 1 เมื่อนับเฉพาะตัวแอปไม่ใช่ตัวเดียวกับอันดับ 1 เมื่อนับรวม data ให้บอกด้วย
4. ถ้ามีแอปที่ "วัดได้ไม่ครบ" ให้บอกว่าตัวเลขนั้นอาจต่ำกว่าจริง เพราะ macOS ไม่ให้อ่านบางโฟลเดอร์ และแก้ได้โดยให้สิทธิ์ Full Disk Access กับ Terminal ที่ System Settings → Privacy & Security
5. ตาราง "ไม่ได้จับคู่กับแอป" รวมของระบบ เครื่องมือ command line (เช่นที่ติดตั้งผ่าน Homebrew) และไฟล์ที่ค้างจากแอปที่ถอนไปแล้ว ถ้ามีรายการใหญ่ให้พูดถึงสั้นๆ แต่อย่าเดาว่าเป็นของอะไรหรือเป็นไฟล์ค้างถ้ายังไม่ได้ดูข้างใน

## ขอบเขต

สกิลนี้แค่วัดขนาด ไม่ลบอะไร เพราะการลบบางอย่างย้อนกลับไม่ได้ ถ้าผู้ใช้อยากเคลียร์พื้นที่ ให้ถามก่อนว่าจะลบรายการไหน แล้วดูข้างในก่อนลบ

ตัวเลข GB ในรายงานเป็นแบบ 1 GB = 1024 MB จึงอาจต่ำกว่าตัวเลขใน System Settings เล็กน้อย เพราะ macOS ใช้ 1 GB = 1000 MB
